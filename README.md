# Spirit University — Smart Classroom Booking System

The project archive is available as `777.zip`. Extract it, install Flask with `pip install -r requirements.txt`, then run `python app.py` and open http://127.0.0.1:5000.

The application includes role-based access, room management, class sessions, bookings, approvals, and student seat booking. Demo accounts are seeded in the source code. Change all demo passwords and configure a strong SECRET_KEY before any deployment.
